PawHaven Design System

Design specification for the stray animal rescue platform — a warm, trustworthy, and professional visual language. Built on @pawhaven/design-system tokens.

Design Principles

Core values that guide every design decision.

01

Warm & Professional

Warm orange as the primary color conveys care and compassion. Earthy brown neutrals create a natural, organic feel. Professional without being cold, warm without being childish.

02

Clear & Actionable

Stray animal rescue is serious work. Every interface must let users immediately know: the current status and what action to take next.

03

Status Visibility

Rescue cases flow through 7 states (Pending → In Progress → Treated → Recovering → Awaiting Adoption → Adopted / Failed). Use color and icons to make status instantly recognizable.

04

Inclusive & Accessible

WCAG AA contrast standards, keyboard navigation support, minimum 44px touch targets, and respect for system preferences.

05

Emotional Resonance

Handwriting accents, warm illustration style, and subtle micro-interactions — so users feel this is a project with heart.

06

Efficiency First

Reduce cognitive load. One-click access to frequent actions, clear information hierarchy. Let volunteers and rescuers focus on saving lives, not learning the system.

Color System

A semantic color system based on existing design tokens. Primary: warm orange (warmth, vitality). Secondary: green (healing, renewal). Backgrounds use brown-tinted warm neutrals to avoid the coldness of pure grays.

Motion & Interaction

Motion system based on existing motion tokens — ensures consistent and delightful interaction experiences.

Easing Functions

Token Value Usage
--ease-out cubic-bezier(0, 0, 0.2, 1) Element entrance, expansion (default)
--ease-in cubic-bezier(0.4, 0, 1, 1) Element exit, collapse
--ease-in-out cubic-bezier(0.4, 0, 0.2, 1) Continuous animations, loops
--ease-standard cubic-bezier(0.4, 0, 0.2, 1) General transitions (MUI default)
--ease-bounce cubic-bezier(0.68, -0.55, 0.265, 1.55) Bouncy effects (use sparingly)

Animation Durations

Token Duration Use Cases
--duration-75 75ms Micro-interactions: button press, checkbox toggle
--duration-100 100ms Hover state changes, tooltip show
--duration-150 150ms Button color transitions, input focus
--duration-200 200ms Card hover, list item highlight
--duration-300 300ms Modal open/close, drawer slide-in
--duration-500 500ms Page transitions, complex animations

Interaction Effects Checklist

🖱️ Hover

Buttons: background color transition 150ms ease-out · Cards: move up 2px + shadow deepen 200ms ease-out · Table rows: background change 100ms · Links: color transition 150ms

👆 Active / Press

Buttons: shrink to 0.97x 75ms ease-out · Cards: no scale (avoids layout shifts) · Inputs: border color + glow 150ms

📋 Focus

All focusable elements: box-shadow: 0 0 0 3px var(--color-primary-subtle) · Border changes to --color-border-focus (brand orange) · Visible focus ring for keyboard Tab navigation

🔔 Notifications & Feedback

Toast: slide in from top-right 300ms ease-out · Auto-dismiss after 5s 300ms ease-in · Loading: skeleton screen pulse animation (opacity 0.5 ↔ 1.0 loop 1.5s) · Form validation: error text fades in 200ms

📄 Page Transitions

Route changes: content area fade-in + slight slide-up (opacity 0→1, translateY 8px→0, 300ms ease-out) · Modal: backdrop fade + dialog scale from 0.95→1 (300ms ease-out)

✨ Emotional Details

Success action: green checkmark bounce animation (--ease-bounce, 500ms) · Adoption success card: heart icon heartbeat scale · Empty state illustration: gentle floating animation (translateY loop ±4px, 3s ease-in-out) · Stat numbers: count-up animation (number scroll 800ms ease-out)
