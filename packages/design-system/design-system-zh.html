PawHaven Design System

面向多平台应用的设计系统规范 — 完整的设计 Token、组件库与交互指南。 基于 @pawhaven/design-system tokens 构建。

设计原则

指导每一个设计决策的核心价值观。

01

一致性

统一的视觉语言贯穿所有界面。使用 Design Token 确保颜色、间距、字体在所有组件中保持一致。

02

清晰可操作

每个界面必须让用户立即理解：当前状态是什么、下一步该做什么。减少认知负担，让操作路径最短。

03

状态可视化

用颜色、图标和文案明确传达系统状态。加载中、成功、失败、空状态等都应有清晰的视觉反馈。

04

包容无障碍

WCAG AA 级对比度标准，支持键盘导航，所有交互元素至少 44px 触控区域，尊重用户系统偏好。

05

优雅克制

动效服务于功能，不喧宾夺主。适度的微交互提升体验，而不是分散注意力。

06

效率优先

信息层级清晰，常用操作一键可达。组件设计遵循最小惊讶原则。

色彩系统

基于 Design Token 的语义色彩体系。主色为暖橙（活力、引导），辅色为绿色（积极、成功）。 背景使用暖调中性色，避免纯灰的冰冷感。

动效与交互规范

基于 motion tokens 的动效系统，确保一致且愉悦的交互体验。

缓动函数

Token值用途
--ease-outcubic-bezier(0, 0, 0.2, 1)元素出现、展开（默认缓出）
--ease-incubic-bezier(0.4, 0, 1, 1)元素消失、收起
--ease-in-outcubic-bezier(0.4, 0, 0.2, 1)持续动画、循环动画
--ease-standardcubic-bezier(0.4, 0, 0.2, 1)通用过渡
--ease-bouncecubic-bezier(0.68, -0.55, 0.265, 1.55)弹入效果（少量使用）

动画时长

Token时长适用场景
--duration-7575ms微交互：按钮按下态、复选框切换
--duration-100100ms悬浮态变化、tooltip 显示
--duration-150150ms按钮颜色过渡、输入框聚焦
--duration-200200ms卡片悬浮、列表项高亮
--duration-300300ms弹窗打开/关闭、抽屉滑入
--duration-500500ms页面过渡、复杂动画

交互动效清单

🖱️ 悬浮态 (Hover)

按钮：背景色过渡 150ms ease-out · 卡片：上移 2px + 阴影加深 200ms ease-out · 表格行：背景色变化 100ms · 链接：颜色过渡 150ms

👆 点击态 (Active/Press)

按钮：缩小至 0.97x 75ms ease-out · 卡片：无缩放（避免布局抖动）· 输入框：边框颜色 + 外发光 150ms

📋 聚焦态 (Focus)

所有可聚焦元素：box-shadow: 0 0 0 3px var(--color-primary-subtle) · 边框变为 --color-border-focus（品牌橙色）· 键盘 Tab 导航可见清晰焦点环

🔔 通知与反馈

Toast：从右上角滑入 300ms ease-out · 5s 后自动消失 300ms ease-in · 加载状态：骨架屏脉冲动画（opacity 0.5 ↔ 1.0 循环 1.5s）· 表单验证：错误提示从透明淡入 200ms

📄 页面过渡

路由切换：内容区淡入 + 轻微上移（opacity 0→1, translateY 8px→0, 300ms ease-out）· 弹窗：背景遮罩淡入 + 弹窗缩放从 0.95→1（300ms ease-out）

✨ 情感化细节

成功操作：绿色对勾弹跳动画（--ease-bounce, 500ms）· 空状态插画：轻微浮动动画（translateY 循环 ±4px, 3s ease-in-out）· 统计数字：计数增加动画（数字滚动 800ms ease-out）
