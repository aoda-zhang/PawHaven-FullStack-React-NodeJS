# Timeline

Compound timeline primitives for ordered events or progress.

## Usage guidance

Compose exported parts chronologically and do not rely on color alone to convey status. `TimelineDot` is decorative by default; pass `aria-hidden={false}` when the dot carries an icon that assistive technology should read.

## Tests and examples

Regression tests are colocated in this component directory. Interactive examples live in `[Timeline.stories.tsx](./Timeline.stories.tsx)`.
