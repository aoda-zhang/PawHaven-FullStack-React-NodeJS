# Skeleton

Lightweight loading placeholder accepting div attributes and a class name.

## Usage guidance

Replace it with final content when loading completes; reduced-motion preferences are respected. The placeholder is a `role="status"` region named "Loading" unless the caller passes its own `aria-label`.

## Tests and examples

Regression tests are colocated in this component directory. Interactive examples live in `[Skeleton.stories.tsx](./Skeleton.stories.tsx)`.
