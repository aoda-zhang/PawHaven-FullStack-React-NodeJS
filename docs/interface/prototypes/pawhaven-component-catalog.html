Body Scale

Body Large — Lead paragraphs and story introductions. Used sparingly to create breathing room around important introductory text.
--font-size-lg1.125rem / 18pxWeight 400LH: 1.625
Body Default — The workhorse. Main body copy across all screens. Set at 16px with comfortable 1.5 line-height for readability.
--font-size-base1rem / 16pxWeight 400LH: 1.5
Body Small — Supporting text, metadata, and secondary information that should recede visually from primary content.
--font-size-sm0.875rem / 14pxWeight 400
Body Caption — Timestamps, legal text, and tertiary labels. The smallest readable size before micro-text.
--font-size-xs0.75rem / 12pxWeight 400
