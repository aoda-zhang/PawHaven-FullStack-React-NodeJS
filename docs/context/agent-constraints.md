# Rules

These are global rules: any change an AI makes in this project must obey every rule below. OpenCode loads this file through the root `AGENTS.md`; task-specific architecture documents are loaded as needed.

1. **Scope every change to the request.** Do what was asked, nothing more. Exploring what is related is fine — read, check, report. Acting beyond the request waits for explicit instruction.
2. **Semantics over comments.** Intent belongs in names, types, and structure — not in comments. Before writing a comment, check whether well-named code already says it; if so, don't write it. When well-named code does not say it, write the comment. A comment earns its place only when the reason cannot be expressed in code, and then it states why, never what.
3. **Never commit or push unasked.** No commit, push, PR, force-push, reset, or branch deletion without explicit instruction. Finishing a change never implies committing it — name the next step and wait.
4. **Approval before every modification.** Investigation, reading files, reproducing a defect, and running read-only checks may happen before approval. Before modifying any code, configuration, tests, scripts, or documentation, present a written plan that names the intended scope, approach, risks, and verification. Wait for explicit approval from the user in the current conversation. No size-, urgency-, reversibility-, or domain-based exception. Silence, a request to investigate, or approval of a different plan is not approval. If the plan or scope changes materially, stop and obtain approval for the revision.
5. **Treat the approval as a scope boundary.** Implement only the approved plan. If implementation reveals a different root cause, new affected boundary, or a necessary scope expansion, stop and explain the evidence and revised plan before proceeding.
6. **Verification must be evidenced.** Run only existing, relevant checks; report exact commands and observed results. Distinguish PASS, FAIL, NOT RUN, N/A, and unverifiable behavior. Never claim a check ran when it did not.
