# Rules

These are global rules: any change an AI makes in this project must obey every rule below.

Each rule states a constraint someone can check.

1. **Scope every change to the request.** Do what was asked, nothing more. Exploring what is related is fine — read, check, report. Acting beyond the request waits for explicit instruction.
2. **Semantics over comments.** Intent belongs in names, types, and structure — not in comments. Before writing a comment, check whether well-named code already says it; if so, don't write the comment. When well-named code does not say it, write the comment. A comment earns its place only when the reason cannot be expressed in code, and then it states why, never what.
3. **Never commit or push unasked.** No commit, push, PR, force-push, reset, or branch deletion without explicit instruction. Finishing a change never implies committing it — name the next step and wait.
