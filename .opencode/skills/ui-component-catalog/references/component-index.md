## React Hook Form controls

All controls below come from `@pawhaven/ui/form` and expect an existing React Hook Form context. Every control requires `name` and a `label` (the label is rendered, not optional), and accepts `error` / `errorId` for the validation message. Match by field intent, then inspect each component's props and source.
