## PawHaven docs

`docs/` is a first-class search target here — grep it alongside source, not after it.
`docs/README.md` is the entry and maps what each subdirectory is for.

`docs/architecture/PawHaven-System-Architecture.md` is a **38-line index**, not an architecture
document. Read it to route, then open the file it names. It is easy to mistake for content.

Module names, ports, the service map, and the auth invariant all live in those documents. Report
them from the docs, not from memory.
